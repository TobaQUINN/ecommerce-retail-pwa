# Non-Negotiables

These principles should never be violated unless explicitly approved.

## Customer Trust

Never request payment before order verification.

Never display inaccurate pricing.

Never display products that do not exist.

Never fabricate stock availability.

Never create fake reviews or testimonials.

Always communicate honestly with customers.

---

## User Experience

Mobile experience always takes priority.

Navigation must remain simple.

The website should remain fast even on slower internet connections.

Every page must have loading, empty and error states.

Accessibility is mandatory.

---

## Product Images

Only use authentic product images.

Do not use misleading promotional images that create unrealistic expectations.

Optimize images before upload.

---

## Engineering

Never duplicate business logic.

Never hardcode configuration values.

Never expose secrets.

Keep components reusable.

Prefer simple solutions over clever ones.

---

## Documentation

Major architectural decisions must be documented.

Update documentation whenever project direction changes.

---

## Future Development

Avoid shortcuts that make future expansion difficult.

Design for scalability without overengineering.

## Realism & Customer Expectations

The website must accurately represent the products and business.

AI-generated imagery must not be used as a substitute for real product photography when it could cause customers to form unrealistic expectations.

Real product images should be used for actual products whenever available.

Real store photography should be preferred when representing the physical store.

Do not invent testimonials, reviews, product popularity, delivery claims, inventory or brand associations.

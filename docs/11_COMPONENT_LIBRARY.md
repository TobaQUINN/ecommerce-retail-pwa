# Component Library

## Purpose

Maintain a consistent, reusable and scalable component system across the application.

Every component should have a single responsibility and be reusable wherever possible.

## Component Principles

Every component should:

- Be reusable.
- Be responsive.
- Be accessible.
- Be typed.
- Support loading states where appropriate.
- Follow the Design System.
- Remain visually consistent.

Avoid duplicate components that solve the same problem.

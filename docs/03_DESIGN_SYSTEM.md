# Design System

## Design Philosophy

The interface should be clean, modern, premium and approachable.

Every screen should prioritize clarity before decoration.

Customers should immediately understand where they are, what they can do and what happens next.

## Layout

- Mobile-first design.
- Responsive across phones, tablets and desktops.
- Maximum content width for large screens.
- Consistent spacing throughout the application.

## Spacing Scale

Use a consistent spacing system.

| Size | Usage |
|------|------|
| 4px | Small gaps |
| 8px | Icons |
| 12px | Small padding |
| 16px | Default spacing |
| 24px | Section spacing |
| 32px | Large spacing |
| 48px | Hero spacing |
| 64px | Major sections |

## Border Radius

| Component | Radius |
|-----------|--------|
| Buttons | Medium |
| Inputs | Medium |
| Cards | Large |
| Modals | Large |
| Images | Medium |

Avoid sharp corners.

## Shadows

Use soft shadows only.

Never use harsh shadows.

Cards should appear elevated without looking heavy.

## Color Palette

Primary

- Black
- White

Accent

- Gold

Supporting

- Green
- Red
- Gray

Never rely on color alone to communicate status.

## Typography

### Heading

Large

Bold

High contrast

### Subheading

Medium weight

Readable

### Body

Simple

Comfortable line height

Easy to scan

## Buttons

Primary Button

- Filled
- High contrast
- Rounded corners

Secondary Button

- Outlined
- Less visual emphasis

Danger Button

- Reserved for destructive actions

Buttons should have:

- Hover state
- Active state
- Disabled state
- Loading state

## Product Cards

Every product card should contain:

- Product image
- Product name
- Price
- Availability badge
- Short description
- Category
- Add to Cart button

Cards should maintain equal height within a grid.

## Status Badges

Supported badges:

- In Stock
- Limited Stock
- Out of Stock
- New Arrival
- Best Seller
- Sale

Badges should be visually consistent.

## Forms

Every form should include:

- Labels
- Placeholder text where appropriate
- Validation
- Error messages
- Success feedback

Never rely on placeholder text as labels.

## Tables

Tables should be:

- Responsive
- Searchable
- Sortable where necessary

Admin tables should support filtering.

## Icons

Use one icon library throughout the project.

Icons should communicate meaning without overwhelming the interface.

## Images

Product images should:

- Show the actual products.
- Maintain consistent aspect ratios.
- Load efficiently.
- Support zoom on the product page.

## Motion

Animations should be subtle.

Examples:

- Fade
- Slide
- Scale
- Hover elevation

Animation duration should generally remain between 150–300ms.

## Accessibility

Every page should include:

- Proper heading hierarchy
- Keyboard navigation
- Screen reader support
- High color contrast
- Focus indicators

## Responsive Breakpoints

Support:

- Mobile
- Tablet
- Laptop
- Desktop

The mobile experience always takes priority.
